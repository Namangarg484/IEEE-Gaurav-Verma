\section*{S4. Validation of the label-construction detector}
Synthetic label columns of 20 subjects, 200 rows per reference value; a
corrupted subject has a contiguous fraction of its rows replaced by the
cross-join pattern (its $k$ reference values cycled row by row).  Thirty
replicates per condition.  The detector is \texttt{detect\_label\_cycling}
(whole column) and \texttt{detect\_label\_cycling\_local} (block scan,
$b=256$, stride 128, $\tau=0.98$, $\ell_{\max}=32$) in
\texttt{ppgbench.integrity}; the experiment is \texttt{validate\_detectors.py}.
Residual misses at $k=2$ are draws in which a subject's two reference values
coincide, so that the column contains no cycle to detect.

\section*{S5. Validation of the null-anchored decision rule}
Each synthetic cohort has 16 subjects $\times$ 12 records $\times$ three
overlapping 5-s windows generated by a pulse model with heart-rate
variability, respiration and noise.  Label $=$ subject offset
($\mathcal{N}(120, 20^2)$, not encoded in the signal) $+\,g\,(\mathrm{HR}-70)$
$+\,\mathcal{N}(0, 3^2)$, with within-subject HR SD 8~bpm.  Each subject has
a label-independent pulse-shape fingerprint (second-harmonic amplitude
$\sim U(0.15, 0.75)$, notch amplitude $\sim U(0.05, 0.45)$).  Models use the
nine hand-crafted features of the main paper; predictions are averaged per
record and scored with 2\,000 subject-cluster bootstrap draws.
